# Calpace CLI

Official Command-Line Interface for [Calpace](https://github.com/Calpace).

[![npm version](https://img.shields.io/npm/v/calpace.svg)](https://www.npmjs.com/package/calpace)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

## Installation

You can run `calpace` directly using `npx`:

```bash
npx calpace
```

Or install it globally via `npm`:

```bash
npm install -g calpace
```

## Usage

```bash
# Run default command
calpace

# Greet a specific user
calpace hello "Alice"

# Display version
calpace --version

# Display help
calpace --help
```

## Options & Flags

| Option | Shorthand | Description |
| --- | --- | --- |
| `--help` | `-h` | Show help and available commands |
| `--version` | `-v` | Display the installed version |
